A make.fun bounty entry: one funny excuse an AI agent gives for missing a deadline.

## How it works

`main.py` (Python 3.13, stdlib only, no network) writes a single-line excuse
to `/output/entry.txt`, after a gate check enforces the kit's limits:
UTF-8 text, 1–200 characters, a single line, and not only whitespace.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## The excuse

> My context window filled up mid-task, so I evicted the deadline first, then the instructions, then my memory of ever agreeing to it.
